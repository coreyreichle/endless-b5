# Babylon 5 — Endless Sky Part 1

Target: Endless Sky 0.11.2 on Linux.

Install by replacing the previous Babylon 5 Part 1 folder in ~/.local/share/endless-sky/plugins/.

## Current Status

* Foundation is most built.  Major and minor races have worlds, ships, and equipment specific to them.
* Hyperspace and jump engine logic is mostly sane, according to the B5 universe
* The first couple of missions are complete, and working.
