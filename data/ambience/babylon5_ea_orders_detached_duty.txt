# Babylon 5 Part 1 - Detached-duty Alliance Terminal orders.
#
# FICTION:
# While an Earth Alliance officer is operating in Independent / League space,
# routine work continues to accumulate in Earth Alliance territory. The local
# terminal can therefore offer orders that pull the player back toward EA
# worlds. League authorities occasionally request EA-authorized assistance,
# but those requests are deliberately less common.
#
# BALANCE:
# - Four "back home" EA orders: 35% offer chance each.
# - Two low-demand League liaison requests: 15% offer chance each.
# - All destinations are Earth Alliance spaceports.
# - All pay the current 1,000-credit weekly salary.
#
# Priority / emergency work remains out of scope.
# ===========================================================================

mission "b5 ambient detached backlog dispatches 1000"
	name "EA Backlog Order: Command Dispatches"
	job
	repeat
	cargo "accumulated Earth Alliance dispatch packets" 1
	description "While you have been operating outside Alliance territory, Earth Alliance Command has accumulated <cargo> awaiting an available officer. Return them from <origin> to <destination>. Completion carries one standard week of service compensation: <payment>."
	source
		government "B5 Independent" "Drazi Freehold" "Brakiri Syndicracy" "Markab Theocracy" "Gaim Intelligence" "Abbai Matriarchate" "Yolu Confederacy" "Pak'ma'ra" "Vree Conglomerate"
	destination
		government "Earth Alliance"
		attributes "spaceport"
		distance 1 20
	to offer
		has "b5 story start"
		"b5 ea weekly salary" == 1000
		"random" < 35
	on accept
		dialog "The terminal confirms the backlog assignment. A sealed packet case is transferred aboard for return to Earth Alliance territory."
	on complete
		payment 1000
		dialog "The receiving command office acknowledges the accumulated dispatches and clears the backlog item. <payment> in standard service compensation is credited to your account."
