# Babylon 5 Part 1 - Earth Alliance ambient orders.
#
# JOB BOARD FICTION:
# In Endless B5, the Job Board represents an Earth Alliance orders terminal.
# The player remains an Earth Alliance officer regardless of the government
# controlling the planet where the terminal is accessed.
#
# A mission's source filter controls which locally relevant requests appear;
# it does NOT imply that the local government employs the player.
#
# PAY:
# Endless Sky 0.11.2 requires a numeric mission payment. Each salary tier
# therefore needs matching order variants gated by "b5 ea weekly salary".
# This initial set matches the current 1,000-credit weekly salary.
#
# ROTATION:
# Each routine order has a 40% offer chance. At a typical major-faction port,
# one universal order plus five local orders are eligible, producing an average
# of 2.4 visible Alliance Terminal orders per evaluation.
#
# Priority and emergency orders remain disabled below.
# ===========================================================================

mission "b5 ambient ea terminal dispatch 1000"
	name "EA Dispatch Order"
	job
	repeat
	cargo "sealed Earth Alliance dispatches" 1
	description "Earth Alliance Command has authorized the transfer of <cargo> from <origin> to <destination>. This routine order is available for pickup through the local Earth Alliance terminal. Completion carries one standard week of service compensation: <payment>."
	destination
		attributes "spaceport"
		distance 1 8
	to offer
		has "b5 story start"
		"b5 ea weekly salary" == 1000
		"random" < 40
	on accept
		dialog "Earth Alliance Command confirms the order. The <cargo> is released to your vessel for delivery to <destination>."
	on complete
		payment 1000
		dialog "The receiving office confirms delivery and closes the order. <payment> in standard service compensation is credited to your account."
